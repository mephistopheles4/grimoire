PROTOTYPE · issue 402 · Decisions tab

The right column is a mock of the docked Brigade pane on Desktop, with a third tab added beside Sessions and Pull requests. Only the Decisions tab is drawn; the other two are stubs.

Flip the variant with the white bar at the foot, or the arrow keys. Each variant puts the same parts together a different way: the decision log, the Read tick, Flag to revisit, the filters, the lead's hand-off and the auto-mode switch.

Use the bar's Auto mode default button to see the tab with auto mode starting on or off. That default is an open question for the spec: nothing here settles it.

Every row is invented sample data. Nothing is saved: a reload starts fresh.
