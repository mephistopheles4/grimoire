# Easily undone: the four tests

`SKILL.md` lets an easily undone act go on after its say-back, with no yes
(Requests). Read this file at the start, with `tuning.md`. Nothing here is a
setting: the person does not tune it, and no session writes it.

An act is easily undone when it passes all four tests:

1. You can put it back yourself, right after, in one step: close an issue you
   filed, restore a comment or a scratch file, set a card back, or send a
   correction to a session you messaged.
2. It costs nothing: no money, no paid run, no usage beyond the turn.
3. It reaches no one beyond the person's own tracker (with the people and
   tools it already notifies), their own sessions or your scratch files, and
   the record is not public (in doubt, it is public).
4. No rule you run under keeps it for the person's own confirmation, whether
   the person's, the session's configuration's or a repository's.

A message to another session that relays the person's own request goes on
after its say-back, as any easily undone act; the session that gets it keeps
its own rules for what it then does. An issue goes on only without a label that
hands it to an agent.

Easily undone: filing or editing an issue or a comment in the person's own,
non-public tracker, a message to another of the person's sessions, editing a
scratch file, changing a roster or status card.

Not easily undone: an issue or a comment on a public record, an edit to a
repository file, a commit, a push, a merge, a delete, an install, a settings
change, a start that spends usage, anything with a cost. Closing an issue you
just filed, as its put-back, is not a delete.

In doubt, an act is not easily undone.
